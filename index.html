League Simulator Uploader

League Simulator Uploader is a private command-line tool used by a single YouTube creator to publish videos to their own channels:

  • League Simulator 101 (English)
  • 서위트칠리 Sweetchilly (Korean)

What it does

The videos are short game-combat experiments rendered by the creator's own simulator. Once a day, the tool uploads a finished video to the creator's own channel as private with a scheduled publish time, using the YouTube Data API (videos.insert). It also reads the authenticated account's own channel name (channels.list, mine=true) to confirm the upload goes to the right channel.

Who can use it

Only the channel owner. The tool is not offered to the public, has no other users, and does not access, collect or store data about any other YouTube users.
