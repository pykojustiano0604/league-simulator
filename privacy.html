Privacy Policy

League Simulator Uploader · Last updated: October 19, 2026

League Simulator Uploader ("the tool") is a private tool operated by a single individual to upload videos to their own YouTube channels. This policy explains what data the tool uses.

Use of YouTube API Services

The tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Data the tool accesses

  • An OAuth 2.0 token for the channel owner's own Google account, with the scopes youtube.upload and youtube.readonly.
  • The owner's own channel name and ID (to confirm the upload destination).
  • Video files and titles/descriptions created by the owner.

How data is used and stored

The token is stored only on the owner's own computer and is used only to upload the owner's videos and read the owner's channel name. No data is sent to any server other than Google's YouTube API. The tool does not collect, store, sell or share any personal data, and it does not access data of any other YouTube users.

Revoking access

Access can be revoked at any time at Google security settings. Deleting the locally stored token removes all stored authorization data.
